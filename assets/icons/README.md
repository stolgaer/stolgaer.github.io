# Profile link icons

These local SVGs are shown only in the compact layout. The desktop layout retains text links. Icon colors were adapted to the site's burgundy (#8B0000); the original shapes are unchanged.

- Google Scholar, ResearchGate and GitHub: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0.
- LinkedIn: [Font Awesome Free](https://github.com/FortAwesome/Font-Awesome/blob/7.x/svgs/brands/linkedin-in.svg), Icons CC BY 4.0. The original copyright and license comment is retained in the SVG.
- IDEAS/RePEc: [Academicons by James Walsh](https://github.com/jpswalsh/academicons/blob/master/svg/ideas-repec.svg). The original attribution and SIL Open Font License metadata is retained in the SVG.

All logos remain the property of their respective owners. No third-party scripts or font libraries are loaded.
